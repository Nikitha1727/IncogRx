# Person A — Secret Wards handoff

This directory contains the original resources, standalone helpers, synthetic test harnesses and draft documentation from phases 1–6. These files are separate from the existing IncogRx runtime. Copy or integrate selectively after checking interfaces.

Phase 0 benchmark: see phase2_detection_tests/practice_baseline_summary.json and phase6_documentation/EVIDENCE.md. These are historic starter results, not scores for the current IncogRx implementation. The final brief is a draft and must be updated with measured integrated results and the actual project identity.

Raw practice data, truth.json, detailed patient-level leak audits, credentials, caches and temporary outputs are deliberately excluded. Run audit scripts locally, with output outside this repository.

The files in this folder do not change the repository's main entry point or existing pipeline.
